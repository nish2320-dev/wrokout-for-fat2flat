## App Review Information

Sign-in required: **No**.

Notes for the reviewer:

```
No account or sign-in is needed; all data is stored on the device.

To try the main features:
1. Home → Generate workout → choose options → Start. Tap "Log" on a set to start the rest timer (a local notification fires when rest ends).
2. Meals → Search → type "coffee" or "protein shake" → pick a result → Add to today.
3. Meals → Scan → point the camera at any packaged-food barcode. Product data comes from Open Food Facts (openfoodfacts.org).

The camera is used only to read barcodes; no photos are taken or stored.
```
